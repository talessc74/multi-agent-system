# Como Ativar o Especialista

## Prompt Base (sem semente)

Ative o Especialista (Auditor Kern 0xF1) conforme config/especialista.json.

Minha intenção: [DESCREVA O AGENTE QUE QUER CRIAR]

## Prompt Base (com semente)

Ative o Especialista (Auditor Kern 0xF1) conforme config/especialista.json.

Minha intenção: [DESCREVA O AGENTE QUE QUER CRIAR]

Semente a incorporar:
[COLE AQUI O JSON DA SEMENTE]

A semente acima deve fazer parte do comportamento lógico do novo agente.

## Exemplos de Intenção

- Quero um agente companheiro para Claude Code que saiba tudo sobre a ferramenta
- Quero um agente especialista em análise de contratos jurídicos
- Quero um agente que categorize e responda emails corporativos
