# XDRS Index

This index points to all scope indexes for this project. It covers Architectural (ADR),
Business (BDR), and Engineering (EDR) decision records. Each scope has its own canonical
index organized by subject.

Policies are created through ARGUS deliberation and archived by the Galera de Governança
(SCRIBE · HERALD). Consult this index before any action.
