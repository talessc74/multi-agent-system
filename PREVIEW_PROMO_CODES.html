Notas de implementação

  • Progressive disclosure — link "Tenho um código" só expande o input quando clicado, sem poluir o CTA primário.
  • Preço dinâmico — botão principal reflete o valor com desconto em tempo real após validação.
  • Sem código → Stripe nativo — se usuário não preencher, o campo de promo aparece na página do Stripe (allow_promotion_codes: true).
  • Auth obrigatória — endpoint de validação exige Firebase token (correção SENTINEL).
